# 📈 금융 시황 자동 수집 & 블로그 자동 임시저장 파이프라인

매일 아침 국내 증시, 비트코인, 나스닥, 미국 에너지 섹터 시황을 자동으로 수집하고, 전문 금융 분석가 AI(Gemini / OpenAI)를 통해 리포트를 작성한 뒤, 블로그(워드프레스 또는 티스토리)에 **'임시 저장(Draft)'** 상태로 안전하게 업로드하는 자동화 시스템입니다.

---

## 🏗️ 시스템 아키텍처 (3단계 모듈 구조)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 데이터 수집부 (collectors.py)                            │
│    - Google News RSS 피드 실시간 호출 (feedparser)          │
│    - 키워드: 국내 증시, 비트코인 시황, 나스닥, 에너지 섹터 │
│    - 기사 제목, 요약, 발행일자, 링크 수집 및 중복 제거      │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. AI 추론부 (processors.py)                                │
│    - Gemini API (또는 OpenAI) 금융 분석가 시스템 프롬프트   │
│    - 1) 국내 주식 단기/스윙 관점 2) 코인 방향성 3) 미국장   │
│    - 블로그 가독성을 위한 정제된 HTML 구조 태그 출력        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. 자동 발행부 (publishers.py)                              │
│    - 워드프레스 REST API (또는 티스토리 Open API)           │
│    - [핵심] status="draft" (즉시 발행 X, 임시 저장 O)       │
│    - 사용자 검토 후 발행 가능한 안전 모드                   │
└─────────────────────────────────────────────────────────────┘
```

---

## 📁 프로젝트 파일 구성

| 파일명 | 역할 및 설명 |
| :--- | :--- |
| **`pipeline.py`** | 3단계 모듈을 순차 실행하는 메인 파이프라인 및 `main()` 함수 (CLI 지원) |
| **`collectors.py`** | 1단계: Google News RSS 기반 금융 뉴스 수집 및 중복 필터링 |
| **`processors.py`** | 2단계: Gemini/OpenAI 기반 전문 금융 분석가 HTML 리포트 생성기 |
| **`publishers.py`** | 3단계: 워드프레스 REST API / 티스토리 임시저장(Draft) 업로더 |
| **`config.py`** | `.env` 환경변수 로드 및 전역 설정 관리 |
| **`.env.example`** | API 키 및 워드프레스 계정 설정 템플릿 |
| **`requirements.txt`** | 필요 라이브러리 목록 (`feedparser`, `requests`, `google-generativeai` 등) |
| **`last_generated_report.html`** | 가장 최근에 생성된 HTML 리포트 로컬 미리보기 파일 |
| **`logs/`** | 일자별 자동화 실행 로그 저장 폴더 |

## 🚀 빠른 시작 가이드 (Setup Guide)

### 1. 패키지 설치
이미 설치되어 있지 않다면 아래 명령어로 필요한 패키지를 설치합니다:
```bash
pip install -r requirements.txt
```

### 2. 환경변수 설정 (`.env`)
`.env.example` 파일을 복사하여 `.env` 파일을 생성합니다:
```bash
copy .env.example .env
```
`.env` 파일을 열고 본인의 API 키 및 블로그 정보를 입력합니다.

#### 🔑 주요 환경변수 안내
1. **`GEMINI_API_KEY`**: [Google AI Studio](https://aistudio.google.com/)에서 무료로 발급받은 API 키를 입력합니다.
2. **`WORDPRESS_URL`**: 본인의 워드프레스 사이트 주소 (예: `https://myblog.com`)
3. **`WORDPRESS_USER`**: 워드프레스 관리자 계정 아이디
4. **`WORDPRESS_APP_PASSWORD`**: **워드프레스 애플리케이션 비밀번호**
   - 일반 로그인 비밀번호가 아닙니다!
   - 워드프레스 관리자 페이지 → **사용자(Users) → 프로필(Profile)** 접속
   - 페이지 하단 **'애플리케이션 비밀번호(Application Passwords)'** 섹션 이동
   - 새 애플리케이션 이름(예: `MorningBot`) 입력 후 **'새 애플리케이션 비밀번호 추가'** 클릭
   - 화면에 표시되는 24자리 비밀번호(예: `abcd efgh ijkl mnop qrst uvwx`)를 복사하여 입력합니다.

## 💻 실행 방법

### 1) 사전 테스트 (Dry-run 모드)
블로그에 실제로 업로드하지 않고 뉴스 수집 및 AI 리포트 생성(HTML 로컬 저장)만 테스트하려면:
```bash
python pipeline.py --dry-run
```
생성된 본문은 `last_generated_report.html` 파일로 브라우저에서 바로 확인하실 수 있습니다.

### 2) 전체 파이프라인 실제 실행 (임시 저장 등록)
```bash
python pipeline.py
```
- RSS 뉴스 수집 → AI 시황 분석 리포트 생성 → 워드프레스에 **'임시 저장(Draft)'** 업로드가 순차 진행됩니다.
- 관리자 패널의 글(Posts) 목록에서 임시글을 확인하고 검토 후 발행하시면 됩니다.

## ⏰ 윈도우 작업 스케줄러를 통한 매일 아침 자동 실행 등록

컴퓨터가 켜져 있을 때 매일 아침(예: 오전 7시 30분) 자동으로 실행되도록 설정하는 방법입니다:

1. `Win + R` 누른 후 `taskschd.msc` 입력하여 **작업 스케줄러** 실행
2. 우측 메뉴에서 **'기본 작업 만들기(Create Basic Task)'** 클릭
3. **이름**: `금융 시황 자동 블로그 포스팅` 입력
4. **트리거**: `매일(Daily)` 선택 → 시작 시간: `오전 07:30:00` 설정
5. **동작**: `프로그램 시작(Start a program)` 선택
6. **세부 설정**:
   - **프로그램/스크립트**: 현재 파이썬 실행 경로 (예: `C:\Users\전산실PC_SS_091\AppData\Local\Programs\Python\Python313\python.exe`)
   - **인수 추가(선택 사항)**: `pipeline.py`
   - **시작 위치(선택 사항)**: `C:\Users\전산실PC_SS_091\Desktop\stock\blog`
7. '마침'을 누르면 설정이 완료됩니다. 매일 아침 자동으로 실행되어 워드프레스에 임시글이 생성됩니다.
